TE SHOW THE PING — PUBLIC WEBSITE (FIREBASE / FIRESTORE VERSION)

1. Upload/replace this project in the public GitHub repository.
2. Vercel framework preset: Next.js.
3. Root Directory: ./
4. Keep Build Command / Output Directory / Install Command on Vercel defaults.
5. The public content API is already configured by default:
   https://api-tepisclovernotes-flame.vercel.app/public/bootstrap
6. Optional: add this server-side Vercel environment variable if the API domain changes later:
   CONTENT_API_URL=https://api-tepisclovernotes-flame.vercel.app
7. Deploy the API revision that contains /public/bootstrap BEFORE deploying this website.
8. Push/commit this public project. Vercel will deploy automatically when Git integration is enabled.

DATA FLOW
Firestore -> Express API /public/bootstrap -> Next.js public website

The public project does NOT need:
- Firebase Admin private keys
- Firebase Authentication credentials
- CMS credentials
- Cloudinary API secret

Content is fetched server-side and revalidated approximately every 30 seconds.
Existing Google Drive media records remain compatible while images are gradually moved to Cloudinary.
Cloudinary secure_url/url media records are also supported.
