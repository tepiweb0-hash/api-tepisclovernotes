TEPIS CLOVER NOTES — PUBLIC SITE FIREBASE MIGRATION

This project keeps the original public Next.js layout and pages.
Only the content source has changed:

OLD
  Google Sheets -> Apps Script ?action=bootstrap -> Next.js

NEW
  Firestore -> Express public /public/bootstrap -> Next.js

Default API:
  https://api-tepisclovernotes-flame.vercel.app/public/bootstrap

Optional Vercel environment variable:
  CONTENT_API_URL=https://api-tepisclovernotes-flame.vercel.app

The public app does NOT need Firebase Admin credentials and does NOT need CMS login.
Public content is read server-side by Next.js and cached/revalidated every 30 seconds.

Existing Google Drive media URLs remain supported during the media migration.
New Cloudinary URLs are also supported through secure_url/url.
